Galaxy Creator design system

Monochrome chrome in two themes, floating over a galaxy that holds all the color. Every swatch below is read live from kit.css, and every control is built by ui.js, the same factories the app uses.

UI.setTheme('light' | 'dark' | 'system')

Color

The chrome is greyscale on purpose, so the galaxy is the only color on screen. Ink marks what is active; the three chrome greys build surfaces, fills and hover states.

TokenUsed forLightDark

Galaxy palettes

The one place hue is allowed. Each palette colors four things in the galaxy: old stars, young stars, and two gases.

Type

One family, Geist, from 10.5 px key caps to the 240 px landing headline. Weight carries hierarchy; numbers that change use tabular figures.

Shape and depth

Corners are concentric: a control inset in a card takes the card's radius minus the padding between them, so every gap around a corner is even. One shadow, --lift, separates chrome from the sky.

Sizes

Motion

Springs, not durations: snappy for presses and pills, pop for things that arrive, smooth for panels, and a quick exit curve for anything leaving. Leaving is always faster than arriving.

Icons

24 px grid, 1.6 px strokes, round caps. Icons with a .fill layer fill in when their control is active.

Components

Each factory takes plain options and returns an element. Controls that show a value read it through get and redraw with el.sync(), so the same control can follow any state, the galaxy's or a page's own.
